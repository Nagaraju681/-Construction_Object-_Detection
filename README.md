# 🏗️ Construction Object Detection Using YOLO

## 📌 Project Overview

This project focuses on detecting construction-related objects in images using the YOLO (You Only Look Once) object detection model.

The application uses Streamlit to provide a simple and interactive web interface where users can upload images and perform object detection.

## 🎯 Project Objectives

- Detect construction-related objects from images.
- Use a trained YOLO model for object detection.
- Display detected objects with bounding boxes.
- Build an interactive web application using Streamlit.

## 🛠️ Technologies Used

- Python
- YOLO
- Streamlit
- OpenCV
- NumPy
- PyTorch

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Nagaraju681/-Construction_Object-_Detection.git
```

### 2. Navigate to the Project Folder

```bash
cd -Construction_Object-_Detection
```

### 3. Create a Virtual Environment

```bash
python -m venv env
```

### 4. Activate the Environment

Windows:

```bash
env\Scripts\activate
```

### 5. Install Required Libraries

```bash
pip install -r requirements.txt
```

## 🚀 Run the Application

Execute the following command:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔍 How to Use

1. Open the Streamlit application.
2. Upload a construction-related image.
3. Run the object detection process.
4. View the detected objects and bounding boxes.
5. Analyze the detection results.
